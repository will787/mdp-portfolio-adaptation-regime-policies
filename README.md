# mdp-portfolio-adaptation-regime-policies

This project explores active management procedures by analyzing the relationship between dynamic market variables and macroeconomic indicators using Markov Decision Processes (MDP).

## How to Run the Project

### 1. Setup the Virtual Environment
Run the following commands in your terminal to create and activate a Python 3.11 virtual environment:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
```
*(Note: If you are on Windows, use `source .venv/Scripts/activate` instead)*

### 2. Install Dependencies
Install all the required packages for the model:

```bash
pip install -r requirements.txt
```

### 3. Execute the Analysis
To run the strategies and view the analysis, simply execute the main script:

```bash
python main.py
```
